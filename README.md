# Winnie Song — Personal Portfolio

A responsive English portfolio featuring a professional personal statement, skills, and four project references. Built with plain HTML and CSS; no installation or build is needed.

## Publish with GitHub Pages

1. Create a **public** repository called `winnie-portfolio`.
2. Upload the contents of this folder to the repository root. `index.html` must be at the top level. Preserve the `assets` folder.
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, then **main** and **/(root)**. Click **Save**.
5. When deployment finishes, open the published URL shown on the Pages screen.
6. Submit the public repository URL and the live website URL.

Typical URLs (replace USERNAME with your actual GitHub username):

- Repository: `https://github.com/USERNAME/winnie-portfolio`
- Website: `https://USERNAME.github.io/winnie-portfolio/`
